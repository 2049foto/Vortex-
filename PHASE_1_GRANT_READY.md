# 🌀 Vortex Protocol — Base Grant Application

## Executive Summary

**Vortex Protocol** is a premium portfolio hygiene engine that enables users to consolidate fragmented crypto assets across 11 chains with **zero gas fees on Base**. We drive TVL to Base by making it the destination for all consolidation flows.

---

## 🎯 Problem Statement

1. **$2.3B+** in dust tokens locked across wallets industry-wide
2. Users have **50+ small-value tokens** on average across chains
3. **Security risks** from unknown tokens (honeypots, scams)
4. **High gas costs** make manual consolidation uneconomical

---

## 💡 Our Solution

### Core Value Proposition
- **Scan** → Detect tokens across 11 chains in seconds
- **Score** → AI-powered 20-layer risk analysis
- **Consolidate** → Gasless swaps to ETH/USDC on Base

### Key Differentiators

| Feature | Vortex | Competitors |
|---------|--------|-------------|
| Risk Layers | 20 (ML-enhanced) | 0-5 basic |
| Chain Support | 11 chains | 3-5 chains |
| Gas Cost | **$0 on Base** | User pays |

| Distribution | Farcaster native | Web only |

## 🛠️ Technical Architecture

### Stack
- **Frontend**: Next.js 15, React 19, TailwindCSS
- **Web3**: Wagmi v3, Viem, Coinbase Smart Wallet
- **Backend**: Edge Functions, Drizzle ORM
- **Database**: Neon PostgreSQL, Upstash Redis
- **AA**: Pimlico + Coinbase Paymaster

### Security
- Non-custodial design
- Honeypot simulation (Tenderly)
- 20-layer risk scoring
- Cloudflare Turnstile protection
- Rate limiting & input validation

### Performance
- < 500ms scan time (cached)
- < 200ms API p95 latency
- Edge-optimized globally
