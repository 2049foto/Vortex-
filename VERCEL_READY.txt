═══════════════════════════════════════════════════════════════════════
 🔑 MINIMUM API KEYS CẦN CÓ
═══════════════════════════════════════════════════════════════════════

Để app chạy được, cần ít nhất 6 biến này:

1. DATABASE_URL             → Neon PostgreSQL (free)
2. UPSTASH_REDIS_REST_URL   → Upstash Redis (free)
3. UPSTASH_REDIS_REST_TOKEN → Upstash Redis (free)
4. JWT_SECRET               → Generate local (free)
5. TURNSTILE_SECRET_KEY     → Cloudflare (free)
6. NEXT_PUBLIC_WALLETCONNECT_PROJECT_ID → WalletConnect (free)

💰 Total cost: $0 (tất cả free tier!)
